# Реплики персонажей пьесы Н. В. Гоголя «Ревизор»

В истории русской драматургии, по всей видимости, нет пьес, в которых реплики персонажей совокупно насчитывали нужный для стилеметрического анализа объем, но в пьесе Н. В. Гоголя «Ревизор» (1836) роли Городничего и Хлестакова одни из самых объемных. Тексты собраны автоматически из [Dracor](https://dracor.org/rus/gogol-revizor).

## Состав корпуса

| Имя файла  | Персонаж | Количество слов |
