# Тесты для корпуса

## Общее описание

Набор скриптов для валидации и поддержания качества корпуса текстовых файлов. Скрипты рекурсивно обходят директорию `RSD`, находят папки `corpus` и выполняют различные проверки целостности и консистентности данных.

---

## 1. check_corpus_consistency.py

### Назначение

Проверка соответствия между реальными файлами в папке `corpus` и метаданными в файле `corpus.tsv`.

### Функциональность

#### Основные возможности

- **Рекурсивный поиск** папок `corpus` во всех вложенных директориях
- **Валидация наличия** файла `corpus.tsv` на уровень выше папки `corpus`
- **Сравнение списков файлов** между файловой системой и TSV-файлом
- **Выявление расхождений**:
  - Файлы, присутствующие в папке, но отсутствующие в TSV
  - Файлы, указанные в TSV, но отсутствующие в папке

#### Алгоритм работы

1. Обход всех директорий в указанном корневом каталоге
2. При обнаружении папки `corpus` проверяется наличие `corpus.tsv` в родительской директории
3. Из TSV-файла извлекаются названия файлов из колонки `filename`
4. Собирается список реальных файлов в папке `corpus`
5. Множества сравниваются, расхождения выводятся в консоль

#### Выходные данные

- Для каждого найденного корпуса:
  - ✅ Успешная проверка: количество файлов
  - ⚠️ Расхождения: список отсутствующих/лишних файлов
- Итоговая статистика по всем корпусам

#### Использование

```bash
python3 check_corpus_consistency.py
```

#### Пример вывода

```
🔍 Поиск папок 'corpus' в RSD/
Найдено 3 папок 'corpus'

📂 Проверка: RSD/project1/corpus
   ✅ OK: 15 файлов, все соответствуют

📂 Проверка: RSD/project2/corpus
   ⚠️  РАСХОЖДЕНИЯ:
      🗑️ В папке, но нет в TSV (2):
         - temp_file.txt
         - pushkin_2023.txt
      📝 В TSV, но нет в папке (1):
         - missing_document.txt

ИТОГ: 2/3 проверок пройдено успешно
```

## 2. check_duplicates.py

### Назначение

Поиск дубликатов текстовых файлов внутри каждой папки `corpus` (файлы с идентичным содержимым, но разными именами).

### Функциональность

#### Основные возможности

- **Двухэтапная проверка** для оптимизации производительности:
  1. Группировка по размеру файла (быстрый фильтр)
  2. Сравнение содержимого файлов одинакового размера
- **Поддержка двух методов сравнения**:
  - `hash` (по умолчанию) - SHA256 хеширование (быстро)
  - `content` - побайтовое сравнение (максимальная точность)
- **Обнаружение жестких ссылок** (файлы с одинаковым inode)
- **Детальный отчет** о найденных дубликатах

#### Алгоритм работы

1. Рекурсивный поиск всех папок `corpus`
2. Для каждой папки:
   - Сбор всех файлов
   - Группировка по размеру
   - Для групп с одинаковым размером:
     - Вычисление хешей (или побайтовое сравнение)
     - Объединение идентичных файлов в группы дубликатов
3. Вывод информации о дубликатах

#### Выходные данные

- Для каждого корпуса:
  - Статус проверки (найдены/не найдены дубликаты)
  - При обнаружении: группы дубликатов с перечнем файлов
- Итоговая статистика по всем корпусам

#### Параметры настройки

В классе `CorpusDuplicateChecker` можно изменить:
- `compare_method`: `'hash'` (быстро) или `'content'` (точно)
- `chunk_size`: размер буфера при чтении файлов

#### Использование

```bash
# Стандартный запуск (с хешированием)
python3 check_duplicates.py

# Для изменения метода сравнения отредактировать код:
# checker = CorpusDuplicateChecker("../", compare_method='content')
```

📂 Проверка: RSD/project1/corpus

📂 Проверка: RSD/project2/corpus

## Системные требования

- **Python**: версия 3.6 или выше
- **Стандартные библиотеки**: `os`, `csv`, `pathlib`, `hashlib`, `collections`, `datetime`
- **Операционная система**: Linux / Unix (поддержка inode для определения жестких ссылок)

## Общий формат данных

### Структура директорий
```
RSD/
├── проект1/
│   ├── corpus.tsv
│   └── corpus/
│       ├── file1.txt
│       ├── file2.txt
│       └── ...
├── проект2/
│   ├── corpus.tsv
│   └── corpus/
│       └── ...
└── ...
```

### Формат corpus.tsv

TSV-файл должен содержать колонку `filename` с именами файлов:
```tsv
filename	author	title	year	genre	words	source
file1.txt	Автор	Название	2020	роман	10000	Источник
file2.txt	Автор2	Название2	2021	стихи	5000	Источник2
```

## Известные ограничения

- Скрипты не удаляют дубликаты автоматически (только обнаруживают)
- Не обрабатывают файлы во вложенных поддиректориях внутри `corpus`
- Требуют прав на чтение всех проверяемых файлов

---

## Цель

Скрипты разработаны для обеспечения качества и целостности корпуса текстовых данных.
